# apex-imgui

`apex-imgui` 是一个 Windows 桌面工具，用于加载 ONNX 模型、管理使用配置、选择手柄输入，并通过虚拟手柄输出相关映射功能。

## 主要功能

- 图形化操作界面
- 支持 ONNX 模型加载、选择与刷新
- 支持多套配置文件管理
- 支持手柄输入设备选择
- 支持虚拟手柄输出
- 支持 SmartCore 开关与预览
- 内置武器模板资源，无需手动导入
- 自动记忆窗口状态与当前配置

## 系统要求

- Windows 10/11 64 位
- 建议使用较新的显卡驱动
- 如需虚拟手柄输出，需要安装 ViGEmBus 驱动

首次运行时，如果 Windows 安全提示拦截程序，请按提示选择允许运行。

## 下载与运行

1. 打开本仓库的 **Releases** 页面下载最新版本。
2. 解压下载的压缩包。
3. 运行 `apex-imgui.exe`。
4. 进入程序后，先检查依赖状态、输入设备、配置和模型是否正常显示。

从源码运行：

```bash
dotnet run --project src/apex-imgui
```

或打开 `apex-imgui.slnx` 后在 IDE 中启动。

## 使用前准备

程序主要使用两个目录（开发时放在仓库根目录，与工作目录一致；发布包中与 exe 同级）：

- `Models`：放置模型文件和模型配置文件
- `Configs`：放置你的使用配置文件

模型文件需要包含一个 `.onnx` 文件和一个同名 `.json` 配置文件。例如：

```text
Models
├── apexlegends.onnx
└── apexlegends.json
```

如果 `.onnx` 和 `.json` 不同名，模型不会显示在程序中。

武器模板已内嵌到程序中，正常使用时不需要额外导入模板文件。

## 模型配置文件

模型配置文件是放在 `Models` 目录中的 `.json` 文件。最小示例如下：

```json
{
  "size": 640,
  "conf_thres": 0.25,
  "iou_thres": 0.45,
  "classes": "0,1"
}
```

字段说明：

- `size`：模型输入尺寸，必填
- `conf_thres`：置信度阈值，可选
- `iou_thres`：IOU 阈值，可选
- `classes`：允许识别的类别编号，可选，多个编号用英文逗号分隔

如果不确定这些参数如何设置，请优先使用模型提供者给出的配置。

## 基本使用流程

1. 将模型文件放入仓库根目录的 `Models`。
2. 将使用配置放入仓库根目录的 `Configs`，或在程序内创建新配置。
3. 启动 `apex-imgui.exe`（或在仓库根目录执行 `dotnet run --project src/apex-imgui`）。
4. 在界面中选择输入设备。
5. 选择配置文件。
6. 选择模型。
7. 确认依赖状态正常。
8. 开启 SmartCore。
9. 如需查看识别和性能状态，可打开预览窗口。

## 常见问题

### 模型没有显示

- 确认 `.onnx` 和 `.json` 文件都在 `Models` 目录中。
- 确认两个文件同名，例如 `apexlegends.onnx` 和 `apexlegends.json`。
- 确认模型配置文件中包含有效的 `size` 字段。
- 点击界面中的刷新按钮重新扫描模型。

### 配置没有显示

- 确认配置文件位于 `Configs` 目录中。
- 确认配置文件是有效的 `.json` 文件。
- 点击界面中的刷新按钮重新扫描配置。

### ViGEmBus 未就绪

- 确认已安装 ViGEmBus 驱动。
- 如果界面提供安装或修复入口，可按提示处理。
- 安装后如果状态仍未刷新，重启程序或重启系统。

### 找不到手柄

- 确认手柄已连接，并且 Windows 可以正常识别。
- 在程序中点击刷新输入设备。
- 如果使用无线手柄，确认连接稳定后再刷新。

### SmartCore 无法开启

- 确认 ViGEmBus 状态正常。
- 确认已选择可用的输入设备。
- 确认已选择有效配置。
- 确认已选择有效模型。

### 启动失败或闪退

- 更新显卡驱动后重试。
- 尝试以管理员身份运行。
- 确认程序目录没有被安全软件拦截或隔离。
